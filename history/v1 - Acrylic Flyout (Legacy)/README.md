# Quick Volume

A minimal Windows system tray volume switcher.

## Features
- **Instant Toggle:** Right-click the tray icon to switch immediately between **25%** and **100%** master volume.
- **Right-Click Only:** Left-clicking is ignored so you never trigger unwanted popups or sliders.
- **Starts on Startup:** Automatically creates a shortcut in `%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\Quick Volume.lnk` so it runs on user log in.
- **Can be Closed:** Easily close via the "Close" option in the right-click menu.
- **Differentiated Icon:** Retains the familiar speaker silhouette from the taskbar, redesigned with vibrant **Electric Cyan** dual sound waves so you can instantly tell it apart from the default Windows sound icon.
